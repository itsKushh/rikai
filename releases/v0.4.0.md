## Résumé local

Le compte rendu commence par un aperçu de l’échange, puis regroupe les sujets abordés. Chaque puce renvoie aux passages de la transcription. Les rubriques complémentaires, comme les difficultés ou les suites convenues, s’appuient sur des paroles citées.

Rikai lit la transcription dans l’ordre avec les noms des intervenants. Quand elle tient dans le contexte du modèle, une seule génération suffit. Pour les enregistrements plus longs, le modèle prend des notes par bloc puis rédige un résumé commun.

Le modèle Qwen3-4B-Instruct-2507 est disponible dans **Paramètres → Modèles → Résumé contextualisé** (2,50 Go). Votre modèle actuel reste sélectionné à la mise à jour. Vous pouvez générer une nouvelle version du résumé sur un enregistrement déjà transcrit.
